# Angela Honours

### Experiment Control 
Control code for:
* **IH line sweeps**. Either motor or piezo sweep depending on desired range. Files are sorted by sample for ease of storing experiment parameters
* **SNSPD characterisation**. Efficiency and dark count characterisation
* **Room Temperature Confocal Alignment**. Cryogenic characterisation and alignment can be found in respective control notebook.
